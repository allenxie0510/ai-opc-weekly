# AI OPC 编辑产品升级（2026-11-19）

## 定位和取舍

面向个人创作者、AI 应用开发者、设计师与一人公司经营者。核心产品是有依据、有用途的精选资讯，而非无限聚合或创业机会承诺。看懂行业、改进工作、做好经营是同一资讯库的三种需求入口。方向探测器保留为辅助实验工具。

## 本次检查发现

- 首页仅按时间展示，读者无法快速知道先读什么；缺搜索和分页。
- 关于页仍使用旧的机会情报和来源分级话术，与新采编规则不一致。
- 评分仅有总分；来源类型、关键事实归属和标准不够透明。
- 采集生成额度按信源配置顺序消耗，靠后来源可能没有评估机会。
- 信源没有近期可读样本时仍可能显示 healthy。
- 线上采集正常但候选积压：检查时 58 已发布、37 待审。质量不能只靠采集数量衡量。

## 已实施

- 编辑首页：定位、三类需求入口、近七天主题重点、最新精选、周报和 RSS。
- 资讯库：标题/摘要/推荐理由/来源搜索，多条件筛选，每页20条。
- 阅读页：原文与收录时间分开、来源性质、评分构成、事实摘要归属、纠错入口。
- 公开信源目录与编辑标准，明确官方声明、媒体报道、实践者与社区证据边界。
- 采集改成逐来源轮转评估；新增经正文读取实测的 Stripe 与 Replicate。
- 无近期文章的采集报告标记 empty，数据库读取失败使用明确错误界面。
- 两幅原创概念插图：灰阶拼贴/半调印刷/亮蓝与少量亮绿，标注 AI 概念插图，不冒充新闻现场。
- 保留原文图、收藏、反馈、按需分享二维码和历史周报切换。
- 本轮先核对发布3条实用资讯：RevenueCat促销配置、LangSmith成本归因、OpenRouter管理密钥权限。

## 内容运营验收标准

采集成功不是可信，可信不是有用。总编 Agent 在独立调用中逐条复核，达标后自动发布，不再要求管理员审批。管理员保留微调和删除能力，删除记录阻止同一内容自动回流。每条发布必须有完整原文、可核对日期、关键事实摘录、具体读者和适用限制。评分门槛维持：证据≥3，重要性或实用性≥4。争议、收入和效果声明不能因名气或热度放行。不承诺为了日更或数量发布。

重点观察：阅读到原文点击、有效反馈、收藏和回访；不以页面数量替代价值。总编 Agent 自动处理候选积压；来源失败和事实纠错在后台查看，管理员不承担逐条审批。

## 总编 Agent 自动发布

- 初稿模型与总编复核分成两次独立调用，均使用已配置的 DeepSeek。
- 确定性门槛：原文完整、证据摘录匹配、日期有效且14天内、价值评分达标、重复与管理员删除拦截。
- 总编逐项核对事实、读者影响、归属和宣传倾向；必须返回完整通过裁决，失败或模型错误不发布。
- 未经交叉核实的重大争议不自动推荐，避免把审核工作转嫁给管理员。
- 管理端只提供已发布内容的微调和删除。现有 news_queue 是唯一可变内容来源；版本条件更新避免覆盖并发操作，公开页面单次关联读取避免中间状态。
- 删除保存屏蔽标记，系统按事件与原始URL阻止回流；不需要新增表或数据库迁移。
- 定时资讯与X任务调用总编步骤，周报仅引用已发布精选自动组成。已有手动调整的周报不覆盖。
