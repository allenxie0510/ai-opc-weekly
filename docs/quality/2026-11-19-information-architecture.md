# Information architecture review

- Product: three primary tasks, News → Weekly → Direction discovery. X is a source channel inside News. Saved items, sources, About and account access belong in the account menu.
- Reader experience: mobile header remains one row; explicit menu labels, expanded state, Escape dismissal and outside-click dismissal. No repeated X link at both global and local levels. News starts with a short title; source caveats remain accessible in a disclosure.
- Business: discovery stays visibly core and currently free, with no invented paid offering. News earns repeat attention; discovery turns reader context into candidate comparisons and validation plans. Account creation precedes model use; explanation does not obscure the primary action.
- Founder: preserve original source evidence and user control; reduce repeated reading and decision effort. Weekly selectors show issue number and start date only, with legacy issue numbers retained.

Acceptance: mobile navigation collapsed by default; desktop has exactly three primary links; account submenu remains available anonymously; login route still invokes the existing email flow; no horizontal overflow at 390px; period labels fit; loading uses restrained status animation and respects reduced motion. This is an acceptance checklist, not a claim of an independently measured “90/100” score.
