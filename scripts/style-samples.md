# 主编点评风格样本（few-shot 注入 generate-radar.mjs）

# 用法：
# - 每条样本一行，以 "- " 开头，写 50–100 字，就像你平时写 editor_note 那样
# - 建议 3–5 条；少于 1 条有效样本时脚本自动跳过注入
# - 以 # 开头的行是注释，不会被注入
# - 改完直接 commit 到 main，下一次雷达生成立即生效
#
# 主编口吻特征（从改稿对比中提炼，供撰写新样本参考）：
# - 克制书面语：不用"震撼/疯狂/炸裂"等情绪词，用"感触很深/十分有意思"
# - 第一人称真实经历保留并正式化："我目前也在借助…""我会尝试…"
# - 指代读者用"个体创业者/独立开发者"，不用"你/你的"
# - 结构：现象 → 对个体创业者的意义 → 自身实践或明确判断收尾
# - 判断要落地：给出方向或行动，不中立和稀泥

- 亲眼见证 AI 自动承接各类繁琐工作，感触很深。对个体创业者而言，这意味着能以极低成本承接客服、数据录入乃至部分运营事务，从而把精力聚焦在核心创意上。我目前也在借助 Computer use 功能开展用户走查与产品测试。
- 此前我始终认为 iPad 难以胜任重度生产力工作，但 AI 的出现打破了这种固有认知。倘若能依靠 iPad 实现从代码编写到项目部署的完整链路，它足以成为我重要的主力设备。
- 想法听起来大胆，却十分有意思。作为独立开发者，我时常不自觉堆砌复杂技术栈，反倒丢掉了小而美的极客思路。或许下一个项目，我会尝试做得更加轻量化。
- 这类"幽灵应用"或将催生全新的应用开发范式。未来市场除标准化付费 SaaS 之外，还会涌现大量面向个人的 AI 私有工具。独立开发者不妨重新思考方向：不必一味角逐大众市场，如何满足各类个性化私人需求，会是新机会。
